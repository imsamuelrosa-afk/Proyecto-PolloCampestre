# 🍗 Sistema de Auto-Pedido — Pollo Campestre Santa Rosa de Lima

## 📋 Descripción
Sistema de terminales de auto-pedido y tecnificación del servicio a domicilio 
para la sucursal de Pollo Campestre en Santa Rosa de Lima, La Unión. 
Diseñado para reducir los tiempos de espera en un 40% e incrementar 
la penetración de mercado en la zona norte de La Unión.
